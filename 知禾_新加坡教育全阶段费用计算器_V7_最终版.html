知知禾提醒

AEIS / S-AEIS是“阶段”，不是学校类型备考、等成绩、全日制衔接或临时就读都可归入这一阶段，因此按实际月份算，不做没有意义的“3年AEIS成本”。
Tuition Grant不是简单折扣PR和国际学生获得并接受Tuition Grant通常需要签署协议，并承担毕业后在新加坡实体工作的3年义务；是否获批及具体条款以学校/MOE为准。
押金 ≠ 最终花费本工具把可退押金从净成本里剔除，但纳入第一年现金需求，更接近真实家庭资金准备。
“私立大学”不是一个统一类别很多项目实际是私立教育机构、海外大学新加坡校区或合作项目。比较时要看授予学位主体、学制、总学费和认证，不只看名称。
数据口径与主要官方来源（核验日期：2026-09-18）

政府/政府资助小学、中学、Pre-U：MOE 2023年公布了2024–2026非公民学费调整表。2026月学费：SC学费为S$0；小学PR S$330、ASEAN IS S$595、非ASEAN IS S$1,035；中学PR S$680、ASEAN IS S$1,090、非ASEAN IS S$2,190；Pre-U PR S$760、ASEAN IS S$1,290、非ASEAN IS S$2,540。单层杂费参考为小学S$13、中学S$20、Pre-U S$27；国际学生杂费可能涉及GST。学校实际账单优先。

Polytechnic：Singapore Polytechnic AY2026/27，在MOE Tuition Grant框架下，年度应付费用示例：SC（40岁以下）S$3,177.52、PR S$6,507.52、ASEAN IS S$12,567.99、非ASEAN IS S$13,767.99。不同Poly及不接受TG时费用不同。

自治大学本科：内置NUS、NTU、SMU部分2026官方示例，分别区分有/无Tuition Grant及身份；这不是六所自治大学的统一学费。

Student's Pass / 陪读LTVP：ICA列示Student's Pass申请费S$45 + 签发费S$60；MJV S$30（如适用）。符合条件的Student's Pass学生的一位父母或祖父母可申请相应LTVP，当前申请费S$45、签发费S$60，MJV S$30（如适用）；需21岁以上SC/PR本地担保人。

其他路径：AEIS培训、过渡课程、私立/非政府学校、国际学校、PEI/海外大学项目、住宿与生活费用均为可编辑预算示例，不代表市场平均价。硕士不设置统一“平均价”，仅提供少数具体项目作为演示，实际应以对应入学批次的offer或官网为准。
